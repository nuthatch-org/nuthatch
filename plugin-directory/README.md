# nuthatch (plugin directory edition)

Skills for [nuthatch](https://www.nuthatch-indexer.com), a self-hosted EVM indexer: `evm-indexing`,
`nuthatch-builder` and `nuthatch-subgraph-port`.

The MCP server in this edition, `nuthatch-demo`, is a **public read-only demo** nest on Arc testnet
(https://arc.nuthatch-indexer.com/mcp). It is not your data. To index your own contracts, run
`nuthatch` locally; the skills show how. The Claude Code marketplace edition in `plugin/` runs a
local MCP server instead.

## External services

This edition talks to one service we run:

- **https://arc.nuthatch-indexer.com/mcp** — the public read-only demo nest above, also named in
  `.claude-plugin/plugin.json`. The MCP client sends tool calls and their arguments (including any
  SQL) over HTTPS, plus ordinary HTTP headers. Our proxy access log keeps the caller's IP address
  and the request line (query strings on GET). Details: https://nuthatch-indexer.com/privacy

There is no `.mcp.json` in this folder. `nuthatch mcp` on your machine, and the marketplace edition
in `plugin/`, send nothing to us.

This folder is generated by `scripts/build-directory-plugin.sh` from `plugin/`. Do not edit it by hand.
