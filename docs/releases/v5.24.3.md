Nuthatch 5.24.3 is a patch cut from main so curl and npx users on 5.24.2 pick up the SQL admission change in #3224. There is no storage migration, and no NID, registry hash or sealed segment moves on a node.

## Upgrade guidance

Replace the binary and restart. A 5.24.0, 5.24.1 or 5.24.2 store is used as it is.

## SQL admission

- **The parser now runs within a bound** (#3224). `/sql`, `/explain`, named queries, GraphQL roots, `/sync` and MCP `sql` check a statement's text before it is parsed, and the engine path checks again under the query's deadline. Expression and type nesting are bounded, `CASE` and `INTERVAL` runs count towards the bound, and a second statement inside the bound is refused.
- A statement the parser cannot finish in bounded time or stack now returns an error quickly and does not hold a SQL permit. A deep `CAST`, a deep array or `STRUCT` type, a long `INTERVAL` run or a stacked statement gets a normal `400`, and the next query is still admitted.

## Also on main since 5.24.2

- `audit chain` accepts Polygon's type-`0x7f` state-sync transaction after the Madhugiri fork, so post-fork Polygon blocks that carry one can be verified (#3208).
