Nuthatch 5.24.2 is a patch cut from main so curl and npx users still on 5.24.1 pick up the onboarding fixes those builds missed, together with the rest of what has landed on main since 5.24.0. It is not a security-fixes-only LTS backport: 5.24.1 remains the thin cargo-deny patch on `release/5.24`. There is no storage migration for an existing 5.24 nest that has not opted into a newer feature, and no NID, registry hash or sealed segment moves on a node.

## Upgrade guidance

Replace the binary and restart. A 5.24.0 or 5.24.1 store is used as it is.

- **Onboarding now prefers environment variables for RPC URLs.** `init` and `dev` read `NUTHATCH_RPC`. `init --rpc` still works as an explicit fallback. Nest helpers pass the URL by environment, not argv, so it stays out of `ps` (#3201, #3195).
- **Init's next-step hint is `--backfill 300` on every chain** (#3213), not fifteen `log_window`s (which is 15000 on Base). When the start or tip cannot be read, init suggests the same bounded backfill (#3200). `add`, `schema`, `init --from` and `init --from-subgraph` offer it too (#3185).
- **Quickstart for your own contract** is in the docs, and the reserved-word / from-quoting hint is restated (#3123).
- Opt-in features added on main since 5.24.0 (null block timestamps, Xatu, the audit log, the audit chain) stay off unless you turn them on. A nest that uses `block_timestamps = "null"` is `schema_version = 2` and is refused by an older binary.
- A nest file that is a symlink is now refused (#3159).

## Onboarding and init

- **`NUTHATCH_RPC`** is read by `init` and `dev`; `--rpc` remains the explicit-flag fallback (#3201). `mcp --authoring` also takes the RPC URL from the environment and keeps its log and pidfile private (#3195).
- **`--backfill 300`** is the next-step hint on every chain (#3213), and the suggestion when the start or tip cannot be read (#3200). The same bounded offer appears on `add`, `schema`, `init --from` and `init --from-subgraph` (#3185).
- **`init --from` refuses an option-shaped value** so a mistyped flag is not treated as a source (#3196).
- **Host-repo init** refreshes its AGENTS.md section on re-init (#3190).
- **`dev`** warns when the RPC `getLogs` window collapses to about 10 blocks (#3126), and refuses a taken port before creating the store. The headless recipe detaches and waits for rows (#3187).
- **Backfill progress** counts committed rows, not fetched logs (#3188). When the chunker ceiling drops, only a narrow window is blamed on the RPC (#3177).

## Public and hosted nests

- The public `/mcp` location repeats `Host` and the other server-level proxy headers, because a `proxy_set_header` in a location drops inherited ones (#3207). Hosted-nest scripts take settings as flags or an env file, not the sudo environment (#3207).
- Public `/mcp` offers only the tools whose routes the proxy serves, driven by `NUTHATCH_MCP_TOOLS` (#3206). Address-history prompts whose tools the allowlist withholds are hidden.
- `remove-nest.sh` only removes nests `new-nest.sh` made; `new-nest.sh` validates and quotes the git spec (#3204).
- A browser can complete POST `/mcp` on a public nest (#3191). CORS covers `/sql`, `/explain` and `/mcp` (#3124). The public table route is hardened (#3164).
- Symlinked nest files are refused (#3159).

## Docs and reserved words

- A quickstart for indexing your own contract, and the reserved-word / from-quoting hint, are in the docs (#3123). `sql` will not answer from a foreign nest on `:8288` (#3186). `SHOW TABLES` is allowed on the read-only surface (#3167). MCP `sql` refuses a malformed `at_block`, `at_time` or `limit` (#3169).

## Xatu, audit, and serving

- **Xatu** is an opt-in Parquet history source (#3087, #3088). Each file's logs are spot-checked against `eth_getLogs` before they are served (#3104), and fetched dataset bodies are size-capped (#3194).
- **Audit chain** checks sealed rows against what each block commits to (#3105). Polygon state-sync blocks are verified; Arbitrum is refused by name (#3193).
- **Audit log** is an optional durable, identity-bound log for `/sql`, admin and MCP (#3115). `/explain` and `/diff` are recorded (#3172). Verify fails a deleted prefix, and rotation cannot restart at seq 1 (#3179). Identity comes from the gateway, not the client (#3181). `/sql` no longer takes the QueryMetrics path; a counting-only meter is used (#3127).
- A reference read gateway for optional authN/Z is in `tools/gateway` (#3106).
- `check` and the follower feed use the full served schema (#3180). Serve includes top-level call tables in `/tables`, `/schema` and `/table` (#3170). `/at` is refused on a null-timestamp nest (#3092). A leftover provisional from seal-direct backfill is sealed provisional, not final (#3192).
- In a null-timestamps nest, top-level call rows and blocks-table rows are stamped null (#3171, #3178). A webhook `where` must not lift the delivery query's block bounds (#3160). MCP `wallet_history` sends page 1's generation on later pages; refused kinds are errors (#3189).

## Release, security, and dependencies

- 5.24 is designated the first LTS line (#3162, #3111, #3098). A partner hosting runbook is in the docs (#3152, #3110).
- Each binary and the engine module ship a CycloneDX SBOM under the same attestation as the provenance (#3108).
- The npm dist-tag step fails on registry errors other than E404 (#3203). Untrusted PR text is framed in the Jules review prompt (#3202).
- Burrmill moved to v0.2.0 then v0.3.0; parquet/arrow 59.3.3 dropped the RUSTSEC-2026-0595 ignore (#3089, #3118). The cargo-deny ignores for RUSTSEC-2026-0594 and RUSTSEC-2026-0595 from 5.24.1 remain the policy where those advisories still apply.
- The plugin directory edition lists its external service and a privacy policy URL (#3161).
