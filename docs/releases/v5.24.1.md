Nuthatch 5.24.1 is an LTS, security-fixes-only patch. It teaches cargo-deny to ignore two RustSec
advisories already ignored on main, so the 5.24 line can pass its required checks and be published.
There is no storage migration, and no NID, registry hash or sealed segment moves on a node.

## Upgrade guidance

Replace the binary and restart. A 5.24.0 store is used as it is.

## cargo-deny

- **RUSTSEC-2026-0594** (cookie: private cookie nonces repeat in forking processes) is ignored.
  Nuthatch never forks, uses no cookies, and actix-web is only pulled in by dbsp's types crate
  (#3101).
- **RUSTSEC-2026-0595** (parquet: encrypted-file crypto failure) is ignored. Nuthatch never writes
  encrypted Parquet, and the encryption feature is off (#3103).
