Nuthatch 5.23.0. These notes are drafted as changes land on `main` and finished at release.

## Upgrade guidance

- **A newly scaffolded nest's NID differs from a 5.22 scaffold of the same contracts**, because its
  `llms.txt` now names the `at` tool (#3010). Its data identity is unchanged, and existing nests keep
  their NIDs.
- **An event nest or runtime on a loopback bind behind a reverse proxy** answers `403` on every
  route, naming the `Host` it saw, until it is started with `--public-host <name>`, once per name the
  proxy forwards (#3002). Address-history nests already did this in 5.21. A client on the same
  machine, a bind off loopback and the published Docker image need nothing.
