Nuthatch 5.24.0 makes address-history nests easier to drive from an agent, speeds up cold starts on
public RPCs, and ships the Claude plugin in a directory edition. There is no storage migration, and
no sealed segment, registry hash or data identity moves for an existing nest.

## Upgrade guidance

Replace the binary and restart. A 5.23 store is used as it is.

- **Nothing changes for an existing nest.** The one new nest setting, `block_timestamps = "null"`, is
  off unless you ask for it (#3078). A nest that uses it is `schema_version = 2`, so an older binary
  refuses it, and an indexed nest is refused if it switches to or from null timestamps.
- **A script that matches the text of a `NUTHATCH_INCOMPLETE` refusal** from an address-history nest
  now sees a hint after the prefix (#3050). The prefix is unchanged.
- Every other nest: nothing to do.

## Indexing and RPC

- **Opt-in null block timestamps** (#3078): `nuthatch init --null-timestamps` writes
  `[nest] block_timestamps = "null"`. The nest keeps the `block_timestamp` column and writes `null` on
  every row, so it never buys an `eth_getBlockByNumber` to stamp one. On a chain whose `eth_getLogs`
  carries no `blockTimestamp`, this removes about one header call per log block from a cold start. The
  default stays eager.
- **Factory children backfill in parallel** (#3076): when an endpoint's address cap splits a window's
  address list, the groups are now asked up to `--concurrency` at a time. Same rows, same order, same
  sealed bytes.
- **Batch width is found by bisection** (#3075), between the widest width known to work and the
  narrowest known to fail, instead of halving.
- **Every RPC request sends `User-Agent: nuthatch/<version>`** (#3070). Cloudflare-fronted public RPCs
  answer 403 to a request with none. The string names the software and nothing about the operator.

## Address history and agents

- **`tokentx` rows carry `tokenName`, `tokenSymbol` and `tokenDecimal`** (#3051), read at query time
  from the token and not stored, so stored rows stay deterministic.
- **Uncovered ranges say what to do** (#3050): an `NUTHATCH_INCOMPLETE` refusal now ends with
  `POST /api/watch` for a range that is not watched, or with the block it is covered through for one
  still backfilling.
- **MCP wallet tools** (#3071): an address-history nest serves `/shape` and `GET /api/coverage`, and
  `nuthatch mcp` pointed at one offers `wallet_status`, `coverage`, `wallet_history` and `diff`, plus
  `wallet-history` and `coverage-gaps` prompts. It no longer advertises event-nest tools that answer 404.
- **`dev --detach`** fails with `port_in_use` instead of trusting another nest's `/ready` (#3029), and
  `/ready` and `index_status` report `has_rows`, with `--wait-rows` (#3037).
- **`init` inside an existing project** writes into its own directory, appends where it should and
  reports what it skipped (#3025).
- **Discovery works from zero in an agent shell** (#3035). The Claude plugin moved into a
  self-contained `plugin/` folder (#3020), and `plugin-directory/` is an edition built for Anthropic's
  directory (#3054).

## Analytical SQL

- **Burrmill moves to 0.1.0, then to 8963974** (#3059, #3079). `now()` and `current_timestamp` answered
  the moment the engine was opened, for every statement, so the generated offchain status views read a
  clock stopped at startup. Each statement now gets its own start time. Small statements also plan
  faster.

## Public nests and docs

- A deploy kit for public read-only demo nests, with Arc testnet USDC and Base USDC served under
  `nuthatch-indexer.com/nests/<name>` (#3036, #3057, #3052, #3044).
- Examples and templates: a blocksquare nest (#3045), a viem + Next template and a Scaffold-ETH 2
  extension that ship a nest (#3043). The README points at the create-eth extension repo (#3055) and its
  first screen leads with proof (#3030).
- A hosted-nest showcase kit and runbook (#3058, #3069), and a ThinkPad unattended mode (#3039).
- Discovery eval results for 5.23.0 (#3040, #3046, #3056, #3082), and lead notes for XDC and pharos
  (#3060, #3061).

## Build and dependencies

- `url` is bumped to 2.5.9 for RUSTSEC-2026-0592 (#3083).
- CI wall time per pull request is cut (#3042), and the feature suite runs after the default one
  locally (#3016). `actions/setup-go` and `cargo-deny-action` are bumped (#3062, #3063).
- CLAUDE.md is slimmed, with the detail in `docs/agent-brief/` (#3049), and Claude Code worker hooks
  and agent rules are added (#3019).

## Known issue
