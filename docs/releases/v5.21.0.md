Nuthatch 5.21.0. These notes are drafted as changes land on `main` and finished at release.

## Upgrade guidance

- **An address-history nest on a loopback bind behind a reverse proxy that passes the client's
  `Host`**: it answers 403 on every route until it is started with `--public-host <name>` for the
  name the proxy forwards. The 403 names the `Host` it saw. That name then reads watched data and
  changes nothing: watch, unwatch, the `proxy` module, tracing by hash and the timestamp search stay
  with callers on the machine itself.
- **rotki in a container on Docker Desktop, reaching a nest on the host's loopback**: start the nest
  with `--local-host host.docker.internal`.
- **rotki, or any client, on the same machine as the nest**: nothing to do.
- **Every operator with sealed history**: a restart no longer rehashes every segment before the nest
  serves. Expect a `segment-verify` thread reading at up to 64 MiB/s a minute after start, and again
  every 24 hours.

## Address history

- **A loopback bind answers only a loopback or declared `Host`, on every route.** A web page that
  rebinds a DNS name to 127.0.0.1 could read the watched addresses and their history, and a page or
  a proxy could unwatch them and borrow the operator's RPC, because the nest trusted the socket. A
  request is now this machine only with a loopback `Host` and no proxy header or other site's
  `Origin`; see [operators.md](../operators.md) for the rule and the one proxy shape no header can
  reveal (#2847).

## Sealed segments

- **A restart serves at once, and every segment is still hashed.** The start rereads only segment
  files that changed since a pass last hashed them (`segments/verified.json`); a background pass then
  hashes every segment a minute after start, at up to 64 MiB/s across the process, and every 24 hours
  after, quarantining a mismatch as the start does. `nuthatch publish` hashes each segment before it
  uploads it and refuses one that does not match. See the failure model in
  [operators.md](../operators.md) for when a corrupted segment is now found (#2853).
- **`/sql` and every analytical query cost less on a large nest.** The segment catalogue is parsed
  once per version instead of up to four times a request, imported labels are bound only for a
  statement that reads them, and a session left at a moved watermark is dropped (#2863, #2852,
  #2862).
