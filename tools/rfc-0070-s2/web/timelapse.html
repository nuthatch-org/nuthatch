Scope

What it does, and what it does not.

Does

  • Replays final sealed segments only, from the nest's first block, so the first frame is the true state.
  • Checks every segment's SHA-256 against its content address before reading it.
  • Hashes the frames in the export, so a viewer can check them against a replay of their own.
  • Plays offline: the exported file makes no request of any kind.

Does not

  • Read the hot tail or a provisional segment: a time-lapse ends at the last final segment.
  • Run arbitrary SQL: the query is row-local, and anything else is refused by name.
  • Fit every nest in a tab. A large replay is recorded natively and loaded here.
  • Prove who published the mirror. A hash says the bytes are the bytes, not whose they are.
